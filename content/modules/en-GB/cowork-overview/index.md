# Handing Claude a task with Cowork

!!! note "Synthetic content"
    This module is mock material for the platform proof of concept.

Cowork is for work you would hand to a colleague rather than discuss: several steps, a clear outcome, and something to review at the end.

## Chat or Cowork?

| Use Chat when | Use Cowork when |
|---|---|
| You want to think something through | You know the outcome you want |
| The answer fits in a reply | The work spans several steps or files |

## Brief it like a colleague

1. State the outcome and where the result should go.
2. Point to the files or sources it should use.
3. Say what to check with you before doing.

Always review the result before you share it.
