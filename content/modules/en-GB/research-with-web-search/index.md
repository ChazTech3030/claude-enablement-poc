# Research with web search

!!! note "Synthetic content"
    This module is mock material for the platform proof of concept.

With web search on, Claude can look things up and cite where each point came from.

## Check the sources

- Open at least the key citations and confirm they say what the answer claims.
- Prefer primary sources: the original report, not an article about it.
- Note the date of each source; fast-moving topics date quickly.
