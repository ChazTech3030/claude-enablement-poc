# Connecting Claude Code to your tools

!!! note "Synthetic content"
    This module is mock material for the platform proof of concept.

Model Context Protocol (MCP) servers let Claude Code reach other systems, such as your issue tracker or documentation.

## The rule

Only connect systems your organisation has approved. A connector can read, and sometimes change, whatever the account it uses can reach.

## Before you add one

- Check it appears on your organisation's approved list.
- Use an account with the least access that does the job.
- Remove connectors you no longer use.
