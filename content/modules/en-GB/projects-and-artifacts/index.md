# Projects and artifacts

!!! note "Synthetic content"
    This module is mock material for the platform proof of concept.

## Projects

A project groups related conversations with shared instructions and reference files. Use one per piece of work (a bid, a product, a client) so that context is set once and reused.

**Set up a project well:**

- Give it clear custom instructions: audience, tone, constraints.
- Add only the reference documents the work needs.
- Check membership before adding anything sensitive.

## Artifacts

Artifacts are substantial outputs (documents, code, diagrams, small tools) shown alongside the conversation so you can iterate on them directly.

| Good for | Less suited to |
|---|---|
| Drafts you will refine several times | One-line answers |
| Small interactive tools and diagrams | Final sign-off without review |

## Exercise

Create a project for a real piece of work, write its instructions, and produce one artifact you would genuinely use this week.
